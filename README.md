# Corner Grocer

**Academic Project · SNHU · CS-210: Programming Languages**

A C++ console application that analyzes grocery purchase data, tracks item frequencies, and displays results through interactive search, reports, and a text-based histogram.

## Overview

Corner Grocer processes grocery item data from a text file and counts how often each item appears. Users can search for individual items, view purchase frequencies, and explore the results through a simple menu-driven interface.

## Features

- Search for individual grocery items.
- Display purchase frequencies for all items.
- Generate a text-based histogram of item frequencies.
- Read and process grocery data from a file.
- Navigate features through an interactive console menu.

## Technologies

- C++
- Visual Studio
- File I/O
- Standard Template Library (STL)

This project gave me hands-on experience with file processing, data structures, and menu-driven application design in C++. It also strengthened my problem-solving and debugging skills while working through the logic needed to process and display data accurately.
